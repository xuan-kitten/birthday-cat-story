# 重生之我穿越到了一只小猫身上 · 可编辑

纯前端（HTML / CSS / 原生 JS）的可编辑生日互动小说网页，手机与电脑都能看。

## 打开方式

**推荐**：双击 `启动本地预览.bat`，会自动开 `http://localhost:8800/` 并打开浏览器。
手机在同一 WiFi 下访问 `http://电脑局域网IP:8800/`。

也可以直接双击 `index.html`（播放没问题，但部分浏览器在 `file://` 下禁用 IndexedDB，编辑保存可能失效）。

## 两种模式

- 右上角按钮切换「播放模式 / 编辑模式」。
- 播放：点空白推进文字（打字机，点击立即显示完）；选项按钮走分支；结局显示「再玩一次」。
- 编辑：左侧节点列表、中间可视化舞台、右侧属性面板。

## 编辑要点

| 操作 | 说明 |
| --- | --- |
| 新增节点 | 左栏「＋ 新增节点」，新节点会自动选中并聚焦文字框 |
| 改文字 | 右侧「剧情文字」；`{playerBreed}` 播放时会替换成玩家选的猫品种 |
| 类型 | `text` 点击推进 / `choice` 分支 / `select` 选角 / `end` 结局 |
| 氛围 | 每个节点可选 `mystery` / `tracking` / `daily` / `warm`，播放时平滑过渡；结局自动 warm |
| 配图 | 把 GIF/PNG/JPG 拖进中间舞台，或点「选择图片」；点缩略图可把已有图片绑到当前节点。没配图的节点直接显示背景，不留占位框 |
| 背景图 | 右侧「背景照片」区域拖入照片，或点选缩略图；选角节点已预绑 `assets/1.jpeg`。照片自动 cover 铺满，可调该氛围的压暗程度 |
| 选角选项图片 | 选角节点每个选项左侧有缩略图按钮，点开可选图或上传；播放时变成单只猫左右轮播，点箭头/滑动切换，点「就选它」确认 |
| 说话人立绘 | 每个节点可选「旁白 / 我 / 小白 / 小黑」；「我」显示在文字框右侧（用玩家选的猫），小白/小黑显示在左侧 |
| 图片位置 | 舞台里直接拖动图片；滚轮 / 双指 / 滑块缩放；「复位位置与缩放」可还原 |
| 沿用上一张 | 节点不配图时选「沿用上一张」，播放会继续显示上一节点的图 |
| 跳转 | `text` 节点设 next；`choice` 给每个选项设目标；`select` 设选中后的 next |
| 开始节点 | 任意节点「设为开始节点」，左栏带 ★ |
| 自动保存 | 改动后约 0.4 秒自动保存，顶栏显示「已保存 时间」 |

## 存储与导出

- 剧情配置：IndexedDB（`meta/story`）+ localStorage 双份。
- 图片：IndexedDB（`assets` 表，key 为文件名），避免 localStorage 爆容量。
- 「导出完整包」= 配置 + 图片 base64，可单文件分享；「导出纯配置」= 只有剧情。
- 「导入 JSON」支持两种包；完整包会自动把图片写回 IndexedDB。

## 背景照片

优先级：**本节点 `bg` > 沿用上一节点 > 当前 mood 默认（`bgByMood`）**。

- 背景自动 `cover` 铺满舞台并居中裁切，重要内容请放在画面中间偏上。
- 每个 mood 可设一张默认背景和「压暗」比例（0–70%），在右侧「背景照片」里调整。
- 选角节点 `start` 已绑定 `assets/1.jpeg`，7 只猫以**左右轮播**形式站在画面中央：一次一只，箭头/滑动切换，圆点指示，点「就选它」确认。
- 选角头像已绑好：原图是 `assets/` 里的 7 张品种 PNG，页面使用 `assets/opt/` 下的 512px WebP 压缩版（合计约 342KB）。
- 只有放进 IndexedDB（编辑器里拖入）的图片才会被「导出完整包」打包；直接放在 `assets/` 的文件不会嵌入 JSON，分享给别人的电脑上需要一并拷贝。

## 角色立绘（说话人）

每个节点有「说话人」下拉框，决定文字框两侧的立绘：

- **旁白**：不显示立绘
- **我**：文字框**右侧**，使用玩家在选角时选中的那只猫（`assets/opt/*.webp`）
- **小白 / 小黑**：文字框**左侧**，读取 `assets/小白.png`、`assets/小黑.png`
  （也支持 `.jpg` / `.jpeg` / `.webp` / `.gif`，文件名用角色名即可）

角色图还没放入时，会显示一个带角色名的虚线占位框，放好图片刷新即可。
初始剧情已自动标注：`meet → 小白`、`skip1 → 我`、`end → 小黑`；其余节点按实际台词在编辑器里选一下即可（节点列表会显示说话人）。

## 剧情数据结构（节选）

```json
{
  "version": 3,
  "startNodeId": "start",
  "bgByMood": { "daily": { "src": "bg_home.jpg", "dim": 0.08 } },
  "nodes": {
    "start": {
      "id": "start", "title": "你是谁？", "type": "select", "mood": "daily",
      "text": "先告诉我——你是一只什么猫？", "var": "playerBreed", "next": "intro",
      "img": "", "imgInherit": false, "imgTransform": { "x": 0, "y": 0, "scale": 1 },
      "bg": "1.jpeg", "bgInherit": false,
      "options": [ { "label": "橘白猫", "value": "橘白猫", "img": "" } ],
      "choices": [], "end": false
    }
  },
  "assets": ["cat_cake.gif", "1.jpeg"]
}
```

`type`：`text` / `choice` / `select` / `end`。
`img` 为角色图文件名；留空且 `imgInherit: true` 表示沿用上一节点图片，`imgInherit: false` 表示不显示。
`imgTransform` 的 x/y 是相对舞台宽高的比例（-2 ~ 2），scale 建议 0.2 ~ 4。
`bg` 为背景图文件名；留空时按 `bgInherit` 决定沿用上一节点还是使用 `bgByMood[mood]`，`dim` 为背景压暗比例（0–0.7）。
